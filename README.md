# LUXE — Premium Fashion E-Commerce Store

A responsive multi-page fashion store built with HTML5 and CSS3 only.

## Files
- `index.html` — homepage
- `shop.html` — product listing
- `product.html` — product detail
- `about.html` — brand story
- `contact.html` — contact form layout
- `cart.html` — static shopping bag
- `styles.css` — shared styles and responsive breakpoints

## Run locally
1. Extract this ZIP.
2. Open the `luxe-fashion-store` folder in VS Code, or double-click `index.html`.
3. Recommended: install the VS Code extension **Live Server**, right-click `index.html`, and select **Open with Live Server**.

No npm, build tools, or JavaScript are needed.

## Study plan
1. Read the HTML structure in `index.html`.
2. Study the CSS variables at the top of `styles.css`.
3. Find `.container`, `.navbar`, `.button`, `.product-grid`, and `.section`.
4. Resize your browser to test the 900px and 640px media queries.
5. Change product copy, prices, colors, and images to make the project your own.
6. Push it to GitHub and publish it with GitHub Pages.

## Limitations
The pages and navigation work, but cart contents do not update, sort/category controls are visual only, and forms do not submit to a real service. Add JavaScript or a backend when you are ready for functionality.

## Images
Images load from Unsplash, so an internet connection is needed. Use appropriately licensed images for any commercial project.
